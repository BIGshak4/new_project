# Ten independent entrance designs

User correction, 1 October 2026: the ten Studio variants were too similar. Build ten
genuinely separate identities, different from all prior proposals and one another.
Vary dominant palette, typography, topology, visual material and interaction. No
green family. The goal is attraction and curiosity on arrival, with Voltage Learning
as an engineering-product reference, not a template. Keep all previous studies and
the production application. The explicit ten-live-options request supersedes another
choice gate; this is code-led comparison, not an approved production redesign.

## Direction contract

THESIS: ten entrances into technical practice, each with its own recognizable world,
with product-shaped interactive art rather than interchangeable dashboard cards.

OWN-WORLD: independent systems: Ion (violet/amber spatial silicon), Coral (coral/ink
kinetic poster), Blueprint (cobalt/lemon technical plate), Chrome (ice/silver product
launch), Primary (black and primary-color constructive graphic), Arcade (lilac/pink
game map), Edition (ivory/burgundy engineering magazine), Solar (orange/black radial
poster), Tide (cyan/teal fluid diagram), Noir (charcoal/platinum typographic studio).
No sage/forest palette. Hebrew typography varies across Rubik, Secular One, Heebo,
Noto Serif Hebrew and existing Assistant; mono only for actual technical notation.

STORY: a striking first impression explains interview preparation, offers one small
technical experiment, and leads to a working sample-answer workspace. Comparison
includes mobile, motion off, fullscreen and the previous proposal collections.

FIRST VIEWPORT: Ion surrounds one isometric die with orbiting input controls; Coral
uses split oversized poster lettering and oversized physical switches; Blueprint is
a full-blue engineering sheet; Chrome centers a sculpted keyboard deck under a
precise title; Primary makes the page itself a colored block composition; Arcade
places a navigable mission island beside playful type; Edition uses asymmetrical
serif columns and a red technical cover drawing; Solar cuts a yellow circle into
an orange field; Tide presents an expansive cyan wave and a three-step route;
Noir uses giant outline typography and a narrow framed interview prompt.

FORM: direction seed 9e6466ae assigned index4, Chrome, included at full salience.
Ordered grounded systems: spatial chip launch, kinetic poster, engineering blueprint,
industrial product launch, constructive graphics, game board, engineering magazine.
Explicit request requires all ten, not a single assigned direction. Challengers:
jackfield is competitive for engineering clarity but too specialized as the whole
entrance (Noir retains disciplined state lines); teletext is competitive for play,
but bitmap scale loses Hebrew legibility (Arcade retains spatial game progression);
decollage declined on legibility and domain fit (Coral keeps scale courage);
cinema poster declined on product clarity and domain fit (Solar keeps total color
commitment); processed film declined on precision and domain fit (Noir keeps crop
discipline); paper automata declined on audience fit (Chrome keeps coherent spatial
cause/effect). These are principle transfers, not claimed catalog-world reproductions.
No image comp or borrowed raster is used. Ion, Coral and Chrome use purpose-made
raster product objects with live semantic controls overlaid. The other figures are
native technical geometry. Exact generation prompts and asset paths are recorded
in apps/web/public/design-worlds/provenance.json, using the built-in image tool. The saved originating roll is .impeccable/review/new-worlds-seed.txt.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
