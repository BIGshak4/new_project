# Five-question duel

Mode: Operate. Existing JobRun extension, with Mineral semantic tokens owned by the parallel design chat.

## Direction contract

THESIS: Challenge a friend and answer the same five short questions in a clear, focused competition.
OWN-WORLD: Inherit JobRun typography, semantic paper/surface/ink/action variables, restrained panels and logical RTL spacing; no global palette or landing edits. Local styles adapt automatically to Mineral and existing dark mode.
STORY: Create or accept an invite, both mark ready, answer five timed multiple-choice questions, wait for the opponent and review the result. A separately labelled, playable preview uses a simulated opponent and demonstration coins.
FIRST VIEWPORT: A compact product header, one clear game heading and challenge/join actions; in play, paired player progress above the question, readable countdown and four full-width answer controls. Results explain the outcome and each correct answer.
FORM: Precisely specified local product extension, no concept seed or new world. Source-first sampling chooses five distinct fundamentals and one pre-authored variant per source. No exposure-history selection; only match state persists.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Boundaries

No automatic human review attestation, live schema changes or deployment. New content remains draft until human review. Demo answer data stays outside the live game's import graph. Server determines scoring, timing and coin movement. Preserve the other chat's Mineral work and all existing user data.
